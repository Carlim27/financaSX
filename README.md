#  FinançaSX

Sistema financeiro moderno feito com HTML, CSS e JavaScript puro.

Sem framework.  
Sem backend.  
Sem 4 mil dependências instaladas para mudar a cor de um botão.  
Uma raridade arqueológica da programação moderna.

---

# ✨ Funcionalidades

✔ Controle de entradas e saídas  
✔ Saldo automático em tempo real  
✔ Categorias financeiras  
✔ Alertas de saldo baixo  
✔ Alertas de saldo negativo  
✔ Gráfico dinâmico com Chart.js  
✔ Dados salvos automaticamente no navegador  
✔ Tema automático dia/noite  
✔ Fundo animado interativo  
✔ Layout responsivo  

---

# 🖥 Interface

O sistema possui:

- Dashboard financeiro
- Controle de movimentações
- Lista de transações
- Gráfico financeiro
- Sistema visual automático
- Partículas animadas no fundo

Tudo isso usando apenas front-end.

Milagres ocasionais ainda acontecem.

---

# 🚀 Tecnologias usadas

- HTML5
- CSS3
- JavaScript Vanilla
- Chart.js
